Full PHP + MySQL Server Deployment Guide

You are currently viewing the GitHub Pages Interactive Client. Because GitHub Pages is a static hosting platform, it runs HTML/CSS/JavaScript directly in the browser. To run the full backend with 24/7 background cron scanners, MySQL database persistence, and automatic Telegram bot webhook alerts, choose one of the options below:

Option 1: Run Locally on XAMPP (Free, 2 Minutes)

  1. Open the XAMPP Control Panel on your PC.
  2. Start Apache and MySQL.
  3. Open your browser and navigate to:
    http://localhost/Siganl_agent/
  4. The local PHP server handles all MySQL tables, real-time background market polling, and automated Telegram bot messages.

Option 2: Deploy Free to Cloud Hosting (24/7 Cloud Server)

You can host the PHP & MySQL backend 24/7 online for free using:

  • InfinityFree (infinityfree.com): 100% Free PHP 8.2 + MySQL hosting with cPanel. Upload your files via FTP or Git.
  • Render.com or Railway.app: Supports PHP Docker container + Managed MySQL with free monthly tier.
  • Any cheap VPS (Hostinger / Hetzner): ~$3-4/month for a dedicated Ubuntu/Debian server with Nginx, PHP-FPM, and MySQL.
